# Algorithms and Data Structures in JavaScript

My implementations from the **Data Structures and Algorithms** course at
Picsart Academy (2023). Each file is a standalone implementation written
while working through the course.

## Contents

| Folder | Topics |
|---|---|
| `sortingAlgorithms` | Bubble, selection, insertion, merge, quick (incl. randomized), counting, radix sort |
| `array_stack_queue` | Dynamic array, stack, queue |
| `linkedLists` | Singly and doubly linked lists, self-organizing list |
| `Trees` | Binary search tree, AVL tree, red-black tree |
| `Heap_Hash` | Priority queue (binary heap), hash map |
| `Graphs_Intro` | Graphs as adjacency lists and matrices, weighted and unweighted |
| `Graphs` | Floyd–Warshall, rooting and centering a tree |
| `Disjoin Sets` | Disjoint set union by rank and by size |
| `Greedy` | Activity selection, job scheduling |
| `BackTracking` | N-Queens, Sudoku solver and validator, knight's tour, maze, subset sum, Towers of Hanoi |

## Running

Plain JavaScript with no dependencies: `node <folder>/<file>.js`
